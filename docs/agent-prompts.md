# 通用与跨端任务提示词

以下模板用于让 coding agent 修改 Stock Engine 项目，不是发给股票分析模型的系统提示词，也不替代 `apps/api/app/agents/` 中的运行时提示。复制所需模板并替换尖括号内容；省略不适用项。项目约束统一由 [AGENTS.md](../AGENTS.md) 和其指向的规范维护。

专项提示词分别归档：[前端提示词](agent-rules/frontend/prompts.md)覆盖页面、组件与流式展示；[后端提示词](agent-rules/backend/prompts.md)覆盖 API、迁移、Agent 和量化。本页仅保留跨端实现、通用排障、审查和文档整理模板。

[返回文档总索引](README.md) · [开发规范索引](agent-rules/README.md)

## 跨端功能开发

```text
请在 Stock Engine 实现：<用户可观察的目标>。
范围：<页面/接口/数据流>；验收场景：<输入、操作、预期结果>。
约束：<兼容性、数据模式或性能要求；没有则删除本行>。

先读 AGENTS.md，按触发条件读取专项规范，用源码核实当前能力。
简述拟改文件与影响后，完成已授权范围内的实现、相关测试与文档同步。
沿真实调用链修改，列明涉及的 API、迁移、任务或数据口径变化；仅在关键歧义影响正确性时确认。
按验证矩阵运行受影响检查。最后给出改动、实际验证结果及未完成事项。
```

## 排查故障

```text
请定位并修复：<实际行为>；预期：<正确行为>。
复现条件：<操作步骤、数据模式、错误文本/日志位置>。

先读 AGENTS.md 和涉及模块的规范，复现或建立最小可核验失败路径。
沿页面请求、API、service、worker、事件或产物链路定位首个偏离点，说明根因证据。
修复原因，并用对应行为回归验证；区分本次问题、既有问题和环境限制。
若 shell 卡住，先按全局规则查沙箱日志和进程归属再重试。
不要把猜测、历史测试结果或无法复现的情况写成已解决。
```

## 审查变更

```text
请只审查 <提交/分支/明确文件范围>，对应需求为 <需求说明或链接>。
读取 AGENTS.md、专项规范和直接调用方，检查行为是否符合需求与项目边界。
优先报告可复现的缺陷、契约不一致、数据泄漏、状态恢复和验证缺口。
每条发现写明严重性、文件位置、触发条件、影响及修复建议；区分已证实与待核实问题。
没有 Git 元数据时按指定文件审查，并说明无法比较历史差异；不要虚构基线。
本次只输出审查结果，未经后续要求不修改文件。
```

## 整理文档与规范

```text
请参考 <资料路径>，整理 Stock Engine 的 <文档范围>。
先核对参考资料与当前源码，保留可复用的组织方式，按本项目技术栈和数据边界改写。
AGENTS.md 保持短入口；专项规则按任务触发，事实一处维护并用相对链接引用。
区分当前行为、历史阶段、开发约束和本次验证记录；修正过时指引，不抹去历史证据。
完成文档写入、索引更新、链接/格式与源码事实核验，列明未验证范围。
```
