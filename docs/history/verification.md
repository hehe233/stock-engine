## 修复并保留的回归覆盖

- SQLite 丢失时区后导致行情时间偏移：入库前统一转 UTC。
- 窄屏样式误隐藏 Ant Design 输入框外层：改为仅作用于提示文本的明确类名。
- 中文按钮自动间距影响可访问名称：给重试按钮显式设置 aria-label。
- Windows PowerShell 5.1 的 JSON 数组额外嵌套：移除重复数组包装，实测停止脚本成功。
- 免费采集超时：独立子进程限制总执行时间，延长股票全市场分页上限；显示安全错误描述。
- 个股无源时间：同步报告和异步报告都不借用批次时间，回归测试覆盖。
- 失败任务重试：与新任务共用容量检查和单 API 进程入口锁，不能绕过队列上限。
- 模型任务恢复：已完成模型与工具节点不重复执行，引用证据随最终报告持久化。
- 空白凭证视为未配置；非 ASCII 错误访问密钥返回 401，不触发服务异常。
