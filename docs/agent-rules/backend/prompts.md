# 后端任务提示词

[返回后端索引](README.md) · [公共与跨端提示词](../../agent-prompts.md)

复制所需模板并替换尖括号内容。这些提示词用于 coding agent；股票研究模型的运行时提示仍由 `apps/api/app/agents/` 管理。先读 [AGENTS.md](../../../AGENTS.md)，再按任务读取后端细则。

## API 与业务开发

```text
请在 Stock Engine 后端实现 <目标>。
输入/输出：<字段与语义>；验收：<成功、缺失与错误行为>。

读取后端开发规范，检查 routes/schema/service/provider 与直接调用方。
按现有职责实现校验、事务和任务入队；慢操作沿 worker 的有界执行路径。
明确缺失值、状态码、重复提交与模式隔离；契约变化同步前端 API 类型及模块文档。
运行相关 pytest 和 Ruff，报告行为证据及未验证环境。
```

## 数据库与配置变更

```text
请调整 <数据结构或配置行为>，兼容要求为 <旧数据、历史任务和调用方要求>。

读取后端开发规范，核对 ORM、Alembic 历史和 service 事务边界。
实现迁移及兼容处理，在临时数据库验证升级、历史数据保留和并发版本冲突。
模型配置保持管理入口与不可变版本分离，旧任务继续使用其绑定版本。
核对实际数据库目标；未经任务授权不把试验性迁移应用到用户数据。
同步文档，报告验证使用的数据库与其他数据库的未验证范围。
```

## Agent、任务与 SSE

```text
请改造研究任务的 <图节点/工具/事件/恢复流程>，目标是 <可观察行为>。
兼容要求：<历史任务、事件或客户端要求>。

读 Agent 开发规范与 docs/modules/agent-stream.md，追踪提交、冻结证据、租约、检查点、事件和归档。
新增工具明确输入、权限、预算和证据来源；部分输出保持草稿，完整校验通过才归档。
保留续传、去重、终态分页排空和重试语义；协议变化同步前端与文档。
用相关测试覆盖正常、断线/分页、取消/失败/重试及无效输出拒绝归档。
使用现有 mock 验证模型协议，明确是否实际调用真实供应商。
```

## 数据采集与量化实验

```text
请实现或调整 <数据源/特征/标签/校准/成交规则>。
数据范围与口径：<证券、日期、单位、来源和可见时点>。
验收标准：<统计或交易行为，不以盈利作实现验收>。

读数据与量化规范、量化模块或对应数据源说明。
核实输入、缺失、时间切分、训练/校准/测试边界和版本记录，再实现变更。
新增来源保留失败原因与来源元数据；公开模式不使用合成样本补缺。
增加能发现未来泄漏、错误成交或不可追溯问题的相关回归。
交付实现、运行证据与覆盖限制，区分流程验证和市场有效性。
```
