# 前端任务提示词

[返回前端索引](README.md) · [公共与跨端提示词](../../agent-prompts.md)

复制所需模板并替换尖括号内容。这些提示词用于 coding agent；共同约束由 [AGENTS.md](../../../AGENTS.md)、[页面规范](page-development.md)和[组件规范](component-development.md)维护。

## 页面与交互开发

```text
请在 Stock Engine 前端实现：<用户可观察的目标>。
页面/路由：<目标位置>；验收场景：<操作、输入和预期结果>。

先读 AGENTS.md 与前端页面规范，核对 main.tsx、App.tsx、目标页面、api 和相关测试。
沿用 React Router、TanStack Query、统一 request 与现有组件，完成已授权范围的实现。
覆盖首次加载、刷新保留数据、空结果、失败重试和 mutation 反馈。
若需要改 API 契约，说明原因并同步两端；不通过前端猜测或伪造数据补齐缺失。
运行受影响的类型、ESLint 与浏览器验证，同步模块文档并报告结果。
```

## 组件、样式与响应式

```text
请调整 <组件或页面区域>，目标效果：<布局、交互、参考与约束>。

按 AGENTS.md 读取组件规范与界面框架说明，先检查已有组件、主题 token 和 CSS Modules。
在实际 DOM 与 portal 挂载关系下实现，保持既有数据流和副作用生命周期。
核验桌面、窄屏、临界宽度、键盘与焦点；动画遵循减少动态效果偏好。
涉及公共外壳时检查调用页面，涉及 TSX 时运行类型与规范检查。
交付可观察的界面变化、验证结果以及未验证场景。
```

## 流式展示与报告

```text
请改造 <任务进度/工具展示/报告抽屉>，目标：<预期行为>。

读 AGENTS.md、前端规范、docs/modules/agent-stream.md 和后端 Agent 规范中的 SSE/UI 约定。
追踪 useJobStream → stream.ts → AgentStream/ReportWorkspace，区分任务、连接和展示状态。
保留事件顺序、去重、重试历史与草稿标签；关闭抽屉或折叠侧栏不重建订阅。
不补造未返回的思考内容，沿用安全 Markdown。
用相关浏览器回归验证分页/回放、失败恢复、抽屉交互与移动端；协议若变化同步后端测试。
```

## 前端问题修复

```text
请修复 <实际表现>；预期 <正确行为>；复现 <路径、操作、视口和数据模式>。

按前端规范复现，从请求、Query 缓存、组件状态、DOM 和样式定位首个偏离点。
说明证据并修复根因，选择能发现此回归的最小检查；纯样式不为实现细节补测试。
涉及 SSE、订阅或 effect 时验证清理、重连和竞态。
报告修改文件、验证结果与残留问题；无法复现时明确不确定性。
```
