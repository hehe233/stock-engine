# 行情、研究任务与报告

[返回功能模块索引](README.md)

当前闭环是“查看行情快照 → 提交研究任务 → 查看执行进度 → 读取归档报告”。界面入口为行情工作台、研究任务和分析记录；安装、服务启停与演示模式见[项目 README](../../README.md)。

## 行情与模式

- 公开模式尝试获取 A 股、ETF 和指数的免费行情，采集由独立 worker 执行。失败保留旧快照与原因，不回退演示数据。
- 演示模式使用明确标记的固定样本与隔离数据库。五分钟刷新是采集/读取节奏，不是交易所实时性保证。
- 页面区分个股源时间、批次时间、采集时间与 stale 状态；未知价格、源时间或因子保留缺失。详细语义见[架构与数据约定](../architecture/overview.md)。
- 规则热度由后端程序计算，只适用于满足数据条件的股票；ETF、指数或因子缺失时不输出股票总分。规则热度不是盈利概率。

## 任务操作

1. 在行情工作台选择证券、规则/API/Ollama 模式及可用模型，提交当前快照对应的研究。模型配置见[配置模块](model-profiles.md)。
2. API 返回任务 ID，worker 从持久队列领取任务。任务绑定提交时的行情、配置版本与研究证据；持仓只在明确选择持仓分析时纳入。
3. 任务页展示排队、执行、成功、失败和取消。运行过程通过持久化 SSE 事件呈现，刷新可回放；模型没有提供公开思考字段时不补造。
4. 失败后按允许的状态与次数重试；已有检查点的恢复沿用同一任务线程。远程调用与本地事务无法原子提交，恢复可能重复产生模型调用。
5. 报告草稿在执行中逐步形成；结构、JSON 和引用校验通过后才归档。收起报告抽屉不会取消任务，最终结果可从分析记录再次打开。

模型工具、事件类型、断线续传和报告校验细节统一见[流式协议](agent-stream.md)。证据冻结与持仓边界见[研究模块](research.md)。
