# P3：可复现的策略与概率实验

[返回功能模块索引](README.md)

本阶段建立独立的量化实验工作台：数据版本 → 特征与标签 → 按日期滚动训练/校准/测试 → 成交约束模拟 → 概率误差、资金曲线与模型归档。模型 API 用于解释证据，LightGBM 用于数值预测，两者不能互相替代。

## 验收约定

- 数据集不可变，记录源、选择依据、复权口径、证券范围、哈希与缺失审计；Parquet 存日线、DuckDB 查询，SQLAlchemy 存元数据和运行任务。
- 支持 UTF-8 CSV 导入、模板和校验；可把已有 P2 日线转换为明确标记的精选案例实验数据。演示数据独立，公开源失败不回退演示。
- 预测目标明确显示持有期和涨幅阈值，默认未来 5 个观测交易日收盘涨幅至少 20%。不将它称为连板概率。无涨停制度数据时不推算涨停标签。
- 同日期所有证券进入同一分区，训练、校准与测试严格按时间排序；标签结束日期必须早于下一分区开始日期。特征只读取信号日及以前数据。
- 使用固定参数 LightGBM 和独立校准区的 sigmoid 校准；按日期向前滚动。测试集不能调参或确定阈值。样本/类别不足时失败并说明原因。
- 回测使用信号日之后开盘，100 股整数手、T+1、现金与仓位上限、佣金最低收费、日期对应印花税、滑点及成交量参与上限。停牌、价格触及限制、制度缺失或无法估值时保守记录；不假定涨停队列可成交。
- 展示样本外 Brier、对数损失、AUC（有双类别时）、校准分箱、基准发生率、滚动误差，以及扣费后的资金曲线、交易和拒绝原因。
- 实验绑定数据哈希、参数、代码版本、依赖版本、随机种子与模型文本文件；取消/超时/进程中断有明确状态。
- Agent 可读取已经完成的相关实验摘要，标明实验数据与历史时段，不把历史概率当作当前股票预测。
- 本版是研究验证工具，不自动发布交易模型，不下单。完整历史成分、退市证券及授权 Level-2 仍需实际数据；免费条件下不能声称完成这些覆盖。

## 数据范围的实际限制

P2 的十年案例有事后挑选偏差、前复权修订风险、没有成交量和实际涨跌停价。它们可演示研究流程，不足以证明全市场泛化或模拟实际交易。CSV 提供字段并不自动证明来源完整；审计必须区分结构校验通过与历史覆盖核验。

普通 A 股的历史价格限制不能仅用 10% 猜测，ST、上市初期、创业板/科创板制度与除权都会改变限制。本版要求成交模拟使用数据提供的实际上下限和交易状态；缺失则不撮合。Level-2 委托队列与逐笔撮合不在免费日线的能力范围内。

## 启动与操作

1. 停止现有服务，在 `apps/api` 执行 `uv sync` 安装 LightGBM、scikit-learn、PyArrow、DuckDB；回到根目录执行 `scripts/start-dev.ps1`，自动迁移到当前 Alembic head（P3 的迁移基线为 `0006`）。
2. 打开 `/quant`，选择「转换已归档历史案例」或导入自有 CSV。前者仅使用已经入库的 P2 真实日线，不发起全市场抓取。公开模式没有合成数据按钮。
3. CSV 先校验预览，再确认保存。数据版本不可变，修改数据需导入新版本；不能原地覆盖旧实验依据。
4. 选择训练/校准/测试长度、折数、概率阈值、资金和费用参数，点击「创建滚动实验」。默认 120/60/60 个数据集交易日，3 折；每折平移 60 日，训练窗口长度固定。
5. 报告显示校准前后与发生率基准的误差、分箱、分区边界、按月误差、成交模拟、逐笔预测及文件下载。发生率基准使用各折校准区正例比例，不使用测试区比例生成预测。
6. 任务可取消。worker 中断会标为失败，不偷偷重试；使用相同数据与参数可建立新版本。保存、训练或回测都不调用付费模型 API。

演示：`scripts/start-dev.ps1 -Demo` 后打开实验页，创建合成八证券实验集并运行默认参数。合成集有 4960 行，仅用于验证流程和教学，不能评价实际市场效果。

## CSV 数据契约

| 列                      | 说明                                                             |
| ----------------------- | ---------------------------------------------------------------- |
| symbol                  | 证券代码，例如 600000.SH；公开模式拒绝演示代码                   |
| date                    | 数据集交易日期 YYYY-MM-DD，不允许未来或重复证券日期              |
| open/high/low/close     | 完整正数；高低价必须包含开收盘                                   |
| volume                  | 股，非手；缺失时无法约束成交容量                                 |
| prev_close              | 原始前收盘/除权参考价，辅助识别未处理公司行动                    |
| upper_limit/lower_limit | 当日实际限制价，不能用固定百分比猜测；无可靠限制时留空并拒绝模拟 |
| tradable                | true/false/1/0；空值为未知，不按可交易处理                       |
| available_at            | 精确数据可见时刻，必须带时区；不能用今日采集时间冒充历史可见时点 |
| listed_on/delisted_on   | 可选上市/退市日期声明；同证券必须一致，日线不能超出范围          |

CSV 最大 20 MB、100000 行，至少 30 行，30 行只够入库不代表足够训练。仅接受白名单列，其余列不会进入特征。输入 `selection=historical_universe` 是提供者声明，不会把 `coverage_verified` 变成 true。证券列表和日期声明保存在该数据版本的审计清单，并不是已经核验完成的全市场历史证券主表。

数据集交易日取本版本各证券日期的并集，尚未与交易所历史交易日历逐日交叉校验。某证券在并集中缺行时，跨缺口的回看与未来窗口被剔除；停牌最好提供明确状态行。缺少上市前、退市后及其他证券不能靠填零修补，遗漏结果样本可能产生选择偏差。

## 特征、标签和时间隔离

- 特征 v1：1/5/20 日收盘收益、20 日收益波动、当日振幅/收盘价、收盘价相对 20 日均值、成交量相对 5 日均量。最后一项允许缺失，由 LightGBM 原生处理；不填成伪造的真实量比。
- 标签：`close[t+5] / close[t] - 1 >= 0.2`；未来记录缺失时不生成负例。21 条连续回看记录才开始生成有效特征。
- 每个特征窗口中最晚的数据可见时间需早于下一交易日开盘；缺时间则按收盘后可见作研究假设并记录审计限制。训练和校准的标签结束日及标签可见时间也需早于下一分区。
- 不复权数据若前收盘参考价与上一行收盘差异超过 0.1%，视为待核验公司行动；跨该变化的特征/标签窗口剔除，不把拆股、除权等机械变化当作普通收益。
- LightGBM 固定 80 棵树、深度 3、7 叶、学习率 0.05、正则 1、单线程和固定种子 42。独立校准区使用 logistic sigmoid 校准 raw score；没有用测试集 early stopping 或寻优。
- 每折训练至少 100 行、校准至少 30 行、测试至少 10 行；训练/校准每类至少 5 行。此门槛只防止数值流程失效，不代表统计样本充分。校准可能变差，报告保留原始预测作比较。
- 测试折不重叠；下一折可以使用时间上已经发生的上一折历史，这是 walk-forward，不是随机交叉验证。标签有重叠，因此不输出未经相关性修正的显著性或置信区间。

## 成交模拟的准确边界

当前仅支持 2016 年起沪深主板/创业板的普通 100 股规则。科创板、北交所、ETF 等不套用这套数量制度，记录拒绝原因。CSV 中的涨跌停价和交易状态仍必须完整，未独立核验。

信号收盘后产生，下一数据集交易日开盘尝试买入，买入后经过 5 个交易日再尝试开盘卖出，满足 T+1。它与收盘到收盘标签有不同的收益区间。开盘触及涨停拒买，触及跌停拒卖；停牌、缺价、未知限制、滑点后越界或超过整日量参与上限也拒绝。整日量是事后容量检查，不能证明开盘流动性。

最多同时持有指定数量，每笔预算上限为初始资金/仓位数，现金不足不借款，已有仓位不重复买入。卖出受阻顺延；最后一个测试信号后最多继续管理 25 个数据集交易日，剩余仓位明确列出，不强平伪造成交。

佣金双边按基点计、每笔至少 5 元；滑点单独作用于成交价；卖出印花税 2023-08-28 前 0.1%，之后 0.05%，未另计过户费。未平仓仅按最后可见收盘参考估值；当日缺价或公司行动无法处理时 `valuation_complete=false`，总收益/最大回撤留空，不输出看似完整的成绩。费用和净盈亏按证券汇总，不作因果归因。

## 存储与任务设计

`quant_datasets` 保存名称、模式、来源、SHA-256 与审计清单；`quant_runs` 保存状态、参数、结果和版本。文件默认在 `apps/api/quant_artifacts/{public|demo}/{UUID}/`，由 `QUANT_ARTIFACT_DIR` 修改根目录。备份需要同时覆盖数据库和该目录。当前无自动清理，不应删除仍被实验引用的版本。

Parquet 文件保存日线和样本外预测；DuckDB 使用参数绑定读取固定文件，不接受客户端 SQL 或路径。模型以 LightGBM 文本和 sigmoid 系数保存为 JSON，不加载用户 pickle。训练前校验数据哈希，下载/查看预测前校验产物哈希。计算代码哈希、特征版本、依赖版本和种子进入报告。

独立 worker 同时最多管理一个量化子进程，LightGBM 单线程；最多 5 个排队/执行实验，默认 600 秒总超时。行情采集和原有 Agent 队列继续运行。实验元数据与图检查点职责不同：量化训练任务不使用 LangGraph checkpoint，Agent 只读取成功实验的冻结摘要；不修改当前规则热度分，也不实时发出股票概率。

## 尚未完成的生产能力

全市场历史证券成分/退市覆盖核验、时点数据版本修订、完整公司行动收益处理、独立最终盲测、概率上线门槛与持续漂移监测、完整撮合账本、Level-2 授权接入和实盘执行。当前完成的是可运行、可审计的 P3 研究验证版，不以免费精选数据宣称上述能力已经完成。

任务证据通过 `quant/evidence.py` 读取符合证券、模式和截止时点的实验摘要，再由 `jobs/context.py` 组合。归档历史导入通过 `research/queries.py` 读取；量化模块不直接读取 ResearchSnapshot。

### 产物发布与故障边界

数据集与实验继续使用原有 `quant_artifact_dir/<模式>/<UUID>/` 布局。新版本先写同目录临时文件，再原子替换单个文件；所有必要文件完成且元数据提交后才发布结果。下载和预测分页共用模式、成功状态和完整 SHA-256 校验，哈希计算以流读取，分页仍执行固定 SQL 与参数绑定。

可捕获的写入/提交异常会清理本次未引用版本；数据库提交返回异常时先核实持久化结果，已引用或无法确认的版本保留，避免删掉已提交数据。已有版本目录禁止覆盖。进程强杀或断电可能留下未引用目录，本次没有后台垃圾回收；核实数据库引用前不可按目录时间批量删除。

训练进程中断仍标记失败并由用户重跑；Agent 的检查点恢复不适用于量化。这里只改变职责与故障保护，不改变标签、校准、交易模拟或研究验证口径。
