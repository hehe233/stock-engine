# 工作区界面框架

[返回功能模块索引](README.md)

本项目参考本机 `a2a-frontend` 的聊天侧栏、主题与交互，以及 `ResizableDrawer` / `ReportWorkspace` 的报告布局。其 `a2a-backend` 是 AgentOS 服务端，仅用于理解流式事件；Stock Engine 保留原有 FastAPI / LangGraph 任务协议。

## 结构与导航

- `apps/web/src/App.tsx`：持久应用外壳，分为研究空间、研究记录和工作区设置；显示最近四条真实研究任务。
- `AppShell.module.css`：224px 默认侧栏，可在 200–260px 之间拖动；折叠为 64px 图标栏。宽度与折叠状态保存在浏览器本地。拖拽分隔条也支持左右方向键。
- 侧栏对齐参考 Sidebar：透明菜单行、白底蓝字选中态、14px 文案、16px 图标、悬停显示拖拽手柄；底部账号固定，菜单和最近研究独立滚动。折叠后点击 Logo 展开，悬停或键盘聚焦时显示展开图标。Logo 使用指定雷达 SVG，红底白色图标。
- 顶栏固定，主内容区独立滚动；切换路由回到顶部。折叠侧栏不会卸载分析页或重建 SSE。
- 小于 768px 时使用左侧导航抽屉；支持 Esc、焦点恢复、选择后关闭。320px 起可使用，宽表格保留自身横向滚动。

## 主题与动效

`styles/theme.ts` 管理 Ant Design 配置，`styles/global.css` 管理自定义 CSS 变量。主要颜色为蓝色 `#006ee8`、浅灰侧栏 `#f7f8fc`、白色面板与灰色辅助文字。页面卡片使用 12px 圆角，菜单使用 8px 圆角，行情仍保留红涨绿跌。

侧栏和报告抽屉采用 240ms 过渡，页面进入为 180ms 淡入。系统启用减少动态效果时，停止布局过渡、渐显、加载文字闪动及逐字动画。

业务页共享 `Workbench.module.css`，使用容器宽度适配统计卡片和多列面板，因此收起/拉宽侧栏也会正确调整内容布局。

## 流式分析与报告

分析页仍按事件顺序展示模型公开返回的思考内容、工具参数与结果、逐字 Markdown 正文和生成式报告。没有返回的思考内容不会补造。流式实现与校验边界见 [Agent 流式输出](agent-stream.md)。

报告工作区可用宽度达到 850px 时，右侧显示可拖动抽屉；可用空间不足时改为全宽覆盖抽屉。抽屉高度扣除固定顶栏，内容单独滚动。关闭报告不会停止分析，打开文件卡片可再次查看。

## 验证方式

`e2e/app-shell.spec.ts` 验证导航、宽度持久化、键盘与指针调整、手机菜单焦点和减少动态效果；`agent-stream.spec.ts` 验证外壳交互不重建 SSE、完整输出及报告抽屉。业务回归使用 `start-dev.ps1 -Demo` 的隔离数据库。具体通过结果见 [验证记录](../history/verification.md)。
