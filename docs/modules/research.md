# P2：可追溯的短线研究

[返回功能模块索引](README.md)

本版完成连板梯队与行业聚合、龙虎榜与营业部明细、资金流向、公告链接、持仓导入与条件分析、近十个完整年度（2016—2025）的历史观察案例和同期失败对照，并让 Agent 读取提交任务时冻结的研究证据。

## 验收约定

- 侧栏有短线研究、持仓分析、历史案例入口；有真实模式与明确隔离的演示模式。
- 网络采集由独立 worker 的有界后台任务完成，API 返回 202；页面能看到等待、失败、空结果及上次成功数据。
- 研究批次不可变，带来源、请求日期、源日期（可空）、采集完成时间、缺失/拒绝数和口径说明。不同来源、日期、品种不拼成假全量数据。
- 连板使用来源的连板数，按行业聚合；不靠“涨幅超过 9.9%”推算涨停，不把行业聚合当作相关系数或主力认定。
- 龙虎榜展示上榜原因和买卖净额、席位原名；不猜测营业部背后的个人身份，不使用事后涨跌幅作为当日证据。
- 资金净流入属于供应商按成交单分类的统计，不是账户级真实净买入；无日期的实时资金排名不冒充所选历史日期数据。
- 公告展示日期、标题和原文链接；日期不等于精确披露时刻，标题不代替公告全文。
- 持仓支持 CSV/手动逐笔持仓录入、预览后导入、修改和删除。成本和数量由用户提供；普通 A 股按 T+1，ETF 必须明确确认 T+0/T+1，未知规则不估计可卖数。可卖估计不等于券商实际可卖。
- 十年案例为研究观察目录；抓取日线后按统一 20 个交易日窗口计算收益/最大回撤，并同时展示同期上涨与下跌窗口。没有数据时不补造收益，不声称完成概率回测。
- 每个 Agent 任务冻结提交时可见的研究证据；持仓只在用户明确请求持仓分析时纳入。缺数据的证据工具返回缺失说明。

## 与 P3 的边界

[P3](quant.md) 已实现滚动样本外训练、未来收益事件的概率校准和受成交约束的回测研究版。完整全市场历史证券主表、退市覆盖、Level-2 与交易执行仍未完成。P2 的历史窗口统计保持描述性研究含义，不等同于 P3 的实验结果。

## 启动与操作

已有安装不需要新增服务。执行 `scripts/stop-dev.ps1` 后执行 `scripts/start-dev.ps1`，脚本会将业务库迁移到当前 Alembic head（P2 的迁移基线为 `0004_p2`）。保留 `.env` 和已保存的模型设置，API 端口仍为 8001。演示体验使用 `-Demo`，与公开模式的数据库隔离。

1. 打开 `/research`，切换连板梯队、龙虎榜、资金流向、公告证据。选日期后点击「采集 / 更新」，任务排队并显示状态。龙虎榜盘中可选择最近已披露交易日；查看席位后仍需发起该证券的明细采集。
2. 连板按来源连板数分层，最高板标记为观察候选；行业数量与最近十个自然日内的上一有数据日期对比。资金差值只比较同日、同来源的前一采集批次，不代表真正的五分钟成交资金。
3. 打开 `/portfolio`，手动录入剩余数量与成本，或下载 UTF-8 CSV 模板，上传、预览后确认追加。修改和删除均操作单笔持仓；相同代码、类别、日期、数量、成本、制度的行去重。成本/市值/盈亏以人民币元显示。
4. 普通股票使用 T+1；ETF 必须确认具体产品制度。没有覆盖日期的交易日历时，历史买入持仓的可卖估计保留未知；今日 T+1 买入为零。无行情时不计算虚假亏损。
5. 选择规则、API 模型或 Ollama 后点击「分析持仓」。只有这个明确操作才把该证券持仓加入任务；API 模式将这部分证据发送到所配置的模型服务。
6. 打开 `/history`，获取单个或全部十年案例日线。成功后显示日线数量、覆盖起止日期、最强正收益窗口和最弱负收益窗口，点击「查看数据」核验原始价格。全年窗口并不等于人工选定的主升浪。

## 刷新、延迟与稳定性

- 前端每 300 秒读取研究和持仓数据。worker 在北京时间工作日 09—20 时尝试调度研究采集；不是交易所公告推送，节假日也可能尝试查询。龙虎榜 16 点前优先取已知日历的最近交易日。
- 单 worker 的研究队列串行处理，每个请求有子进程超时；最多 20 个待处理请求，相同查询五分钟内合并。排队和慢源可能让实际刷新超过五分钟，API 不等候网络采集。
- 来源日期未知时保持空值；采集完成时间不能证明行情实时。龙虎榜盘后披露，公告只有日期，资金接口无完整源时刻。源失效、限流或没有返回数据均需在界面核验状态。
- 请求失败保留上次成功批次；成功返回空列表标为「空结果未确认」，不伪造事件。旧批次超过十分钟标记采集陈旧；历史日线本身不需要盘中实时更新。
- 涨停池不含 ST、科创板及部分连续一字板新股。免费源没有覆盖完整性或延迟 SLA，不提供逐笔撮合、委托队列或账户资金。
- 历史来源使用腾讯前复权日线，可能事后修订。强弱窗口重叠且案例由人工选取，没有退市与全市场对照，不能据此估计未来连板概率。

## 数据层与 Agent 阅读路径

| 文件                                | 职责                                                        |
| ----------------------------------- | ----------------------------------------------------------- |
| `app/research_schemas.py`           | 查询、日期、CSV 和持仓输入校验                              |
| `app/providers/research_collect.py` | AKShare 网络采集，运行于隔离进程                            |
| `app/providers/research.py`         | 字段白名单、单位、日期与来源限制，不保留龙虎榜事后收益      |
| `app/services/research_data.py`     | 持久队列、批次查询、行业/资金比较、历史窗口、冻结上下文     |
| `app/services/portfolio.py`         | Decimal 成本、CSV 去重、行情关联、T+1 与集中度              |
| `app/research_routes.py`            | 薄 HTTP 接口，共用已有访问控制                              |
| `app/services/jobs.py`              | 绑定用户所见行情，冻结提交前已入库且日期匹配的研究证据      |
| `app/agents/assistant.py`           | `read_research` / `read_portfolio` 读取任务证据，不临时联网 |
| `migrations/versions/0004_p2.py`    | 采集请求、研究批次、持仓表及任务 context                    |

任务证据以个股源日期限制研究日期；个股源日期缺失时只可按采集日期关联，并保留「未知」限制。这是提交时可复现证据，不是历史时点回测保证。普通任务不包含持仓。

## 新增 API

| 方法 | 路径                          | 用途                                                       |
| ---- | ----------------------------- | ---------------------------------------------------------- |
| GET  | `/api/research/data`          | 类型/日期/关键词分页查询，默认 50、最多 100 行             |
| POST | `/api/research/refresh`       | 202 入队；kind 为 ladder/dragon/seats/flow/notices/history |
| GET  | `/api/research/requests/{id}` | 等待、执行、失败、成功状态                                 |
| GET  | `/api/research/history`       | 十年目录与已采集窗口统计                                   |
| GET  | `/api/portfolio`              | 当前模式持仓与参考估值                                     |
| GET  | `/api/portfolio/template`     | CSV 模板                                                   |
| POST | `/api/portfolio/preview`      | 仅校验，返回有效行与错误行号                               |
| POST | `/api/portfolio/import`       | 校验后原子追加，最多 500 行/次、2000 笔总计                |
| POST | `/api/portfolio/{id}/update`  | 修改一笔                                                   |
| POST | `/api/portfolio/{id}/delete`  | 删除一笔                                                   |

`POST /api/jobs` 新增 `include_portfolio`，默认为 false。报告返回 `research_context`，前端可展开核验。

验收测试见 `tests/test_p2.py` 和 `apps/web/e2e/p2.spec.ts`，实际免费源探测与未验证范围见 [验证记录](../history/verification.md) 及 [来源说明](../data/research-sources.md)。
