## 开发阅读顺序

1. 从本页选择受影响模块，确认用户行为和数据边界。
2. 用[源码导航](../architecture/source-map.md)定位前后端入口，再读实际调用方与测试。
3. 按 [AGENTS.md](../../AGENTS.md) 选择前端、后端或跨端规范。
4. 修改行为后同步所属模块；把实际验证写入[验证记录](../history/verification.md)，不在每个模块复制测试次数。

行情来源与历史数据含义见[数据来源索引](../data/README.md)；安装、启动和数据库切换仍以[项目 README](../../README.md)为入口。
